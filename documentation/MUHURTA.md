# Muhurta Engine

The Muhurta engine ranks time windows for a selected activity.

## Inputs

- Date
- Location
- Activity
- Slot length
- Optional birth chart

## Universal factors

- Tithi
- Nakshatra
- Yoga
- Karana
- Vara
- Hora lord
- Brahma Muhurta
- Sandhya
- Abhijit Muhurta
- Rahu Kala
- Yamaganda
- Gulika Kala

## Personal factors

When birth data is provided, the score also includes:

- Tara Bala
- Chandra Bala
- Ashtama Chandra caution

## Output

Each window includes:

- start time
- end time
- score
- band
- Hora lord
- overlap windows
- reasons
- cautions

## Interpretation

The score is a planning signal. It is not a guarantee. The explanation matters more than the number.
