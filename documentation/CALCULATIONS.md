# Calculation Reference

This project uses sidereal Sun and Moon positions.

## Tithi

Tithi is calculated from Moon longitude minus Sun longitude.

Each Tithi is twelve degrees.

## Nakshatra

Nakshatra is calculated from Moon longitude.

Each Nakshatra is thirteen degrees and twenty minutes.

## Yoga

Yoga is calculated from Moon longitude plus Sun longitude.

## Karana

Karana is half of a Tithi.

## Sunrise basis

The daily Panchangam is calculated at local sunrise.

## Sunrise approximation

The current engine uses a civil sunrise approximation. This is suitable for an early project version. A future version can replace it with a stricter astronomical rise and set calculation.
